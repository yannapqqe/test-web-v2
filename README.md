# 愛友家基金有限公司 (Friends Home Foundation) — 官方網站

歡迎來到 **愛友家基金有限公司 (Friends Home Foundation)** 官方網站儲存庫。本網站旨在展示我們的核心使命、服務項目、運作模式及最新活動資訊，促進跨世代社群共融並推動社區合作。

## 關於愛友家

愛友家基金有限公司是一間以社會使命為導向的企業。我們致力於透過多元化的培訓與實踐機會，培育青年人才及協助再投身社會人士重建自信、掌握技能，並促進跨世代社群共融。我們相信，每個人都擁有改變自我與影響他人的力量。

### 業務重點與核心群體
專注為兩大群體提供能力建設與發展支持：
* **青年人**：提供職前培訓、軟技能發展及社會實踐機會。
* **再投身社會人士**：協助重建職業能力、社會連結與自我價值。

### 服務對象
* **長者服務機構**：護老院、長者日間中心、安老服務單位。
* **社區組織**：社區中心、鄰里互助網絡。
* **教育相關群體**：家長、學生、學校及教育機構。
* **跨代社群**：促進不同年齡層的互動與理解。

## 核心服務與運作模式

### 四大服務形式
1. **創意手作班**
2. **歷奇訓練**
3. **關懷探訪**
4. **活動協辦**

### 運作模式：「培訓 — 實踐 — 反思」
* **培訓階段**：為學員提供專業技能與心態準備。
* **實踐階段**：安排學員在真實服務場景中應用所學。
* **反思階段**：透過專業督導促進學員個人成長與策略調整。

## 社會影響力與合作優勢

### 社會影響
* **對學員**：提升就業能力、重建社會連結、增強自信心。
* **對服務對象**：獲得優質活動體驗、減少社會隔閡、提升生活質素。
* **對社區**：促進跨代共融、建立支持網絡、創造共享價值。

### 合作優勢
* **對機構**：獲得專業設計的活動方案及額外人手支援。
* **對學員**：獲得實戰經驗及專業指導。
* **對社區**：建立可持續的社會服務生態。
